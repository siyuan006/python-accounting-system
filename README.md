# 💰 我的记账软件

一个使用 **Python + SQLite + PyQt6** 开发的个人桌面记账软件。

项目从最初的命令行记账程序逐步重构，目前已经实现账单的添加、删除、修改、查询、统计、备份与恢复等功能，并正在持续完善桌面 GUI。

---

## 📌 项目简介

这是一个适合个人日常使用的轻量级记账软件。

主要目标：

* 记录日常收入与支出
* 快速查询历史账单
* 查看收入、支出和余额
* 按日期、月份进行统计
* 按日期范围查询账单
* 对账单进行分类统计
* 支持数据库备份与恢复
* 提供简单直观的桌面 GUI

项目同时作为个人 Python 学习与软件开发实践项目，用于练习：

* Python 面向对象编程
* SQLite 数据库
* PyQt6 GUI 开发
* 软件模块化设计
* 单元测试
* Git / GitHub 项目管理

## ✨ 当前功能

### 📒 账单管理

* 查看全部账单
* 添加账单
* 修改账单
* 删除账单
* 按日期查看账单
* 按月份查看账单
* 按日期范围查看账单

账单包含：

```text
ID
名称
金额
类型
日期
```

其中账单类型包括：

```text
收入
支出
```

---

### 📊 金额统计

支持：

* 总收入
* 总支出
* 当前余额
* 按日期统计
* 按月份统计
* 按日期范围统计

余额计算：

```text
余额 = 总收入 - 总支出
```

---

### 📂 分类统计

支持按照账单名称进行分类统计。

例如：

```text
餐饮：850 元
购物：600 元
交通：230 元
```

同时支持：

* 所有收入分类
* 所有支出分类
* 指定月份收入分类
* 指定月份支出分类

---

### 🔎 查询功能

支持：

```text
全部账单
按日期
按月份
按日期范围
```

例如：

```text
2026-09-01 ～ 2026-09-25
```

可以查询该时间范围内的所有账单，并同步统计：

```text
总收入
总支出
余额
```

---

### 💾 数据库

项目使用：

**SQLite**

数据库文件：

```text
accounts.db
```

SQLite 不需要额外安装数据库服务器，可以直接运行。

---

### 🖥️ 桌面界面

运行：

```bash
python GUI.py
```

界面结构：

```text
菜单栏      文件 / 编辑 / 数据 / 帮助
工具栏      ＋添加 ✎修改 －删除 │ 导出 备份 恢复
统计卡片    总收入 / 总支出 / 余额（含笔数）
查询区      查询模式 · 关键词 · 类型 · 日期控件
账单表格    只读、可点表头排序、收支着色、双击即修改
状态栏      记录条数
```

查询模式：

```text
全部账单 / 按日期 / 按月份 / 按日期范围
```

关键词与类型筛选对所有查询模式叠加生效。

表格说明：

* 单元格只读 —— 修改请双击该行打开对话框，避免误改后不落库
* 收入金额显示为绿色，支出显示为红色
* 点击表头可排序；统计卡片始终只统计**当前筛选出的**记录
* 增删改之后保持当前筛选条件，不会跳回全部账单

---

### 🔐 数据备份与恢复

支持数据库备份：

```text
accounts.db
        ↓
accounts_backup.db
```

也支持从备份数据库恢复数据。

---

### 📝 日志

项目使用 Python `logging` 记录关键操作。

例如：

```text
添加账单成功
删除账单成功
修改账单成功
数据库查询失败
数据库备份成功
```

日志文件用于帮助定位程序运行过程中出现的问题。

## 🖥️ 项目结构

目前项目结构：

```text
accounting_app/
│
├── account.py
├── account_manager.py
├── account_model.py
├── database.py
├── input_skills.py
├── backup.py
├── export.py
├── logger.py
├── main.py
├── gui.py
│
├── tests/
│   ├── test_account_model.py
│   ├── test_database.py
│   └── test_account_manager.py
│
├── accounts.db
├── requirements.txt
└── README.md
```

各模块作用：

| 文件                   | 作用           |
| -------------------- | ------------ |
| `account_model.py`   | 账单对象模型       |
| `account_manager.py` | 账单业务逻辑       |
| `database.py`        | SQLite 数据库操作 |
| `input_skills.py`    | 输入与数据处理工具    |
| `backup.py`          | 数据库备份与恢复     |
| `export.py`          | 账单导出         |
| `logger.py`          | 日志系统         |
| `main.py`            | 命令行程序入口      |
| `gui.py`             | PyQt6 桌面 GUI |
| `tests/`             | 自动化测试        |

## 🚀 安装与运行

### 1. 克隆项目

```bash
git clone 你的GitHub仓库地址
```

进入项目目录：

```bash
cd accounting_app
```

---

### 2. 创建虚拟环境

Windows：

```bash
python -m venv .venv
```

激活：

```bash
.venv\Scripts\activate
```

---

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

---

### 4. 运行桌面版

```bash
python gui.py
```

---

### 5. 运行命令行版

```bash
python main.py
```

## 🧪 运行测试

项目使用 `pytest` 进行自动化测试。

运行：

* Account 模型
* 数据库操作
* 账单添加
* 账单查询
* 账单修改
* 账单删除
* 日期查询
* 月份查询
* 日期范围查询
* AccountManager 业务逻辑

测试数据库与正式数据库分离，避免测试过程中修改真实账单数据。
